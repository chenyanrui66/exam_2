%================ 摘要 =================
\begin{center}
  {\zihao{4}\bfseries \textbf{摘\quad 要}}
\end{center}
\vspace{0.1cm}

针对问题一，考虑到音爆信号以恒定声速传播、到达时刻与传播距离成线性关系这一物理约束，建立了\textbf{到达时间（TOA）定位模型}，将音爆发生时刻$t_0$与三维位置一并作为未知量，利用\textbf{平方差分线性化}求取初值、\textbf{非线性最小二乘}做迭代精炼，并辅以多初值扫描排除伪解。理论分析表明，4个未知量至少需要4台监测设备定解，但4台恰好定解不具备任何检错能力，实际布置应不少于\textbf{5台}。对题目给出的7台设备数据，通过\textbf{4台子集枚举}与\textbf{残差检验}判定设备D、F记录异常（残差分别为$-19.4$\,km和$-16.2$\,km，折合时间矛盾约57\,s与48\,s），予以剔除；以A、B、C、E、G五台联合解算，得到残骸音爆位置为\textbf{东经110.499°、北纬27.311°、高程约855\,m}，音爆时刻为系统时钟后\textbf{19.3\,s}。子集投票与蒙特卡洛模拟显示，该结果的水平不确定度约为$\pm1\sim2$\,km，主要由个别台站的系统性偏差引起。

针对问题二，将单残骸TOA模型扩展为	extbf{多残骸联合定位模型}，引入0-1关联变量刻画设备读数与残骸的对应关系，建立混合整数非线性优化目标；采用\textbf{解析种子+全站联合验真}的两层策略，将搜索空间从$(n!)^m$压缩到$n^m$次解析求解，再用全部设备的TOA残差筛选真解、以精确覆盖保证一对一关联。理论分析表明，4个残骸需至少\textbf{4台}设备方可定解，但4台无冗余校验能力，工程上应布置\textbf{不少于5台}；几何精度因子（PDOP）计算验证了5台是性价比最高的配置。

针对问题三，利用问题二模型对题目给出的7台设备、28个到达时刻数据进行求解。枚举$4^7=16384$种单事件组合后，经物理边界过滤、全站残差精化，仅保留4个候选，再由精确覆盖唯一确定4个残骸的时空状态。解得4个残骸的音爆时刻分别为$11.9999$\,s、$13.0014$\,s、$14.0000$\,s、$15.0000$\,s，位置呈十字对称分布；全部28个残差落在$\pm0.6$\,ms以内，7台设备全部可靠。求解过程中未使用5秒时间窗约束，但输出结果自然满足该条件，说明模型鉴别力来自全站联合一致性而非时间窗先验。

针对问题四，在$\pm0.5$\,s随机计时误差下对关联--定位模型做三项修正：验真阈值按噪声的蒙特卡洛传播规律统计标定（严阈值取RMSE$<0.55$\,s且max$|$残差$|<0.65$\,s）、多组低条件数种子站批量解析抗种子退化、分级阈值加剩余读数补全的容错机制，修正后关联成功率保持\textbf{100\%}。对问题三数据叠加随机误差做300次蒙特卡洛实验：7台现状3D误差95\%分位达1224\,m、10.4\%的实验超过1\,km，瓶颈在高程方向——台站全在地面且远离音爆点正下方，垂直几何张角不足所致。据此按PDOP精度预算设计加密台网：原7台不动，新增中心1台、内环4台（15\,km）、外环8台（45\,km）共20台，配合``子网定关联、全网提精度''的两阶段求解策略，用问题三定位结果正向模拟新台网数据并盲解反演，3D误差95\%分位降至\textbf{457\,m}、最大810\,m，超标比例\textbf{0\%}，满足误差小于1\,km的要求。六项稳健性压力测试进一步表明，模型的关联鉴别力在各类极端噪声形态下均保持稳健，能力边界为单站2\,s级粗差与超出设计值60\%以上的噪声水平。

%================ 1 问题重述 =================
\section{问题重述}
\subsection{问题背景}
绝大多数火箭为多级火箭，下面级火箭或助推器完成任务后经级间分离装置分离坠落，坠落过程中残骸跨音速飞行并产生音爆。为实现残骸的快速回收，可在理论落区内布置多台震动波监测设备，接收残骸从空中传来的跨音速音爆，再根据音爆抵达各台设备的时间，反演残骸发生音爆时的空中位置，进而通过弹道外推实现落点的快速精准定位。

设音爆发生点为$S=(x,y,z)$，发生时刻为$t_0$，监测设备$i$的坐标为$P_i=(x_i,y_i,z_i)$，记录到的音爆抵达时刻为$t_i$，音爆在空气中的传播速度为$c$，则有
\begin{equation}
  \big\|S-P_i\big\|=c\,(t_i-t_0),\qquad i=1,2,\dots,n,
  \label{eq:background-toa}
\end{equation}
其中，式\eqref{eq:background-toa}描述了音爆点位置、发生时刻与各台设备观测时刻之间的几何约束，是全文各问建模的共同出发点。题目给定$c=340$\,m/s，计算两点间距离时可忽略地面曲率，纬度每度距离近似为111.263\,km，经度每度距离近似为97.304\,km。

\subsection{问题的提出}
基于上述背景，本文需解决以下问题：
\begin{enumerate}[label=\arabic*.]
  \item \textbf{问题一（单残骸定位）}：分析精准确定空中单个残骸音爆位置（经度、纬度、高程）和时间至少需要布置几台监测设备；并从题目给出的7台设备观测数据（三维坐标与音爆抵达时间）中选取合适的数据，计算残骸发生音爆时的位置和时间。
  \item \textbf{问题二（多残骸归属判定）}：空中有4个残骸时，每台设备按时间先后收到4组震动波。建立数学模型，判定设备接收到的各组震动波来自哪一个残骸，并分析确定4个残骸的音爆位置和时间至少需要布置多少台监测设备。
  \item \textbf{问题三（多残骸解算）}：利用问题二的模型，从题目给出的7台设备、每台4组抵达时间的数据中选取合适的数据，确定4个残骸发生音爆时的位置和时间（各残骸音爆时刻互不相同，但差别不超过5\,s）。
  \item \textbf{问题四（含误差修正与布站设计）}：设备记录时间存在0.5\,s随机误差，修正问题二的模型；通过对问题三数据叠加随机误差给出算例并分析结果误差；若时间误差无法降低，给出一种实现精准定位（误差$<1$\,km）的方案，并模拟所需设备位置与观测数据加以验证。
\end{enumerate}

%================ 2 问题分析 =================
\newpage
\section{问题分析}

本文的总体思路如下：先将各台设备的经纬高坐标换算到局部直角坐标系，对观测数据做初步检查；随后以式\eqref{eq:background-toa}为核心建立定位模型，问题一解决单残骸定位与数据筛选，问题二、三在其上扩展出归属判定机制，问题四再针对时间误差做模型修正与布站设计，四个问题层层递进。

\begin{enumerate}[label=\arabic*.]
  \item \textbf{问题一}：该问题属于\textbf{几何定位问题}。每台设备提供1个观测方程，而未知量有位置3个坐标与音爆时刻共4个，故方程数与未知量数的平衡关系决定了设备数量的下限。难点有三：其一，观测方程关于未知量是非线性的，需设计可靠的初值与迭代策略，避免收敛到高程为负之类的伪解；其二，7台设备中可能混有异常记录，直接用全部数据解算会污染结果，需借助冗余观测做检验；其三，题目要求"选取合适的数据"，意味着数据筛选本身就是求解的一部分。拟建立TOA定位模型，用线性化方法提供初值、非线性最小二乘精炼，并以子集枚举和残差检验完成异常数据的识别与剔除。
  \item \textbf{问题二}：该问题属于\textbf{组合关联与定位问题}。4个残骸产生4组音爆，每台设备按时间先后记录4个到达时刻，但设备不知道第$k$个读数来自哪个残骸。难点在于关联未知使观测方程数与未知量数的平衡关系变得复杂，且组合爆炸（$4^7=16384$种单事件候选）要求高效的剪枝与验真机制。拟建立多残骸TOA联合模型，以解析种子生成初值、全站残差验真筛选候选、精确覆盖保证一对一关联，并分析最少设备数。
  \item \textbf{问题三}：该问题属于\textbf{多残骸定位的实例验证问题}。在问题二模型的框架下，代入7台设备各4组抵达时刻的具体数据，求解4个残骸的时空状态，并验证数据质量与5秒时间窗约束。拟沿用问题二的解析种子+全站验真策略，输出各残骸位置、时刻及设备关联方案，以残差诊断验证结果可靠性。
  \item \textbf{问题四}：该问题属于\textbf{误差环境下的模型修正与台网设计问题}。计时误差$\pm0.5$\,s使正确关联的残差从接近零抬升到噪声本身的量级，问题二的严阈值与单组种子站在误差环境下会系统性误杀真解，需按噪声统计规律重新标定鉴别阈值并增设容错兜底；误差分析需用蒙特卡洛模拟把计时误差传播到定位域，量化精度是否达标；若误差不达标且无法降低，则需通过加密台网改善观测几何，以几何精度因子（PDOP）做精度预算确定台数与布局，并用问题三的定位结果正向模拟台站数据、反演验证。拟保留``枚举—验真—覆盖''框架骨架，修正其阈值标定、种子生成与容错机制，再以``子网定关联、全网提精度''的两阶段策略适配加密台网。
\end{enumerate}

\section{模型假设}

\textbf{1. 关于传播介质的假设：}音爆在空气中以恒定速度$c=340$\,m/s沿直线传播，不考虑风速、温度分层等因素对声速的影响。落区范围在百公里量级，声速的局地起伏折算后的距离偏差相对观测误差为小量，该简化可以接受。

\textbf{2. 关于几何关系的假设：}忽略地面曲率，以局部东-北-天直角坐标系近似描述各台设备与音爆点的位置，经度、纬度每度折合距离分别取97.304\,km和111.263\,km。

\textbf{3. 关于观测的假设：}各台设备的时钟严格同步，记录的音爆抵达时刻相对于同一系统时钟零时；问题一至问题三中观测时刻的误差仅为数值舍入量级，显著的偏差只可能来自个别设备的记录异常。

\textbf{4. 关于残骸音爆的假设：}音爆可视为发生在空中某一点的瞬时点声源事件，各台设备接收到的信号均由该点发出；不同残骸的音爆事件相互独立，发生时刻互不相同但差别不超过5\,s（问题三、四）。

\subsection{坐标换算}
按照模型假设2，以设备A（110.241°E，27.204°N）为原点建立局部东-北-天直角坐标系，换算关系为
\begin{equation}
  x_i=(\lambda_i-\lambda_0)\,K_{\mathrm{lon}},\qquad
  y_i=(\varphi_i-\varphi_0)\,K_{\mathrm{lat}},\qquad
  z_i=h_i,
  \label{eq:coord}
\end{equation}

\section{问题一：单个残骸的音爆定位}

对单个残骸，音爆发生点$S=(x,y,z)$与发生时刻$t_0$均为未知量，连同式\eqref{eq:background-toa}即构成定位模型。采用到达时间（TOA）定位方法。

式\eqref{eq:background-toa}的几何含义是：音爆点位于以设备$i$为球心、$c(t_i-t_0)$为半径的球面上，若干球面的交点即为所求。未知量共4个，每台设备提供1个方程，故\textbf{理论最少需要4台设备}。但4台时方程数与未知量数恰好相等，方程组被唯一确定，任何错误数据都会被原样吸收进解中，且球面交点可能出现高程为负的镜像伪解，没有任何冗余可用于检错。因此实际布置应\textbf{不少于5台}，用冗余观测换取检错与平差能力。题目给出7台数据，因此我们还需要判断数据是否全部可用。

将式\eqref{eq:background-toa}两边平方并展开，得
\begin{equation}
  \|S\|^2-2P_i\cdot S+\|P_i\|^2=c^2t_i^2-2c^2t_i t_0+c^2t_0^2.
  \label{eq:squared}
\end{equation}
用第$i$式减去第1式，二次项$\|S\|^2$与$c^2t_0^2$被消去，得到关于$(x,y,z,t_0)$的线性方程组
\begin{equation}
  2(P_i-P_1)\cdot S-2c^2(t_i-t_1)\,t_0=\|P_i\|^2-\|P_1\|^2-c^2\big(t_i^2-t_1^2\big),
  \qquad i=2,\dots,n,
  \label{eq:linear}
\end{equation}
对其做最小二乘解即得定位粗值。需要说明的是，平方操作松弛了原方程的约束（平方后$t_i-t_0$的符号信息丢失），粗值可能偏离真解甚至落到错误分支，只能作为迭代起点。

定义残差
\begin{equation}
  r_i(S,t_0)=\underbrace{\|S-P_i\|}_{\text{几何距离}}-\underbrace{c\,(t_i-t_0)}_{\text{声波距离}},\qquad i=1,\dots,n,
  \label{eq:residual}
\end{equation}
其物理含义为：当前解下点$S$到设备$i$的直线距离与声波在$t_i-t_0$内传播距离之差，单位是米。若解正确且数据无误，所有$r_i=0$；$|r_i|$越大，说明第$i$台设备的观测与该解越矛盾。以粗值为初值，用scipy默认的Trust Region Reflective算法求解
\begin{equation}
  (S^{*},t_0^{*})=\argmin_{S,\,t_0}\ \sum_{i=1}^{n} r_i^2(S,t_0).
  \label{eq:lsq}
\end{equation}
该问题存在多个局部极小（低空解、高空解、镜像伪解），除线性化初值外，另取若干高空初值（高程1000\,m、5000\,m、12000\,m）分别迭代，从收敛结果中选取残差最小且物理合理（高程为正、$t_0$落在观测时间窗附近）的解。完整流程如算法\ref{alg:q1}所示。

\begin{algorithm}[H]
\caption{问题一求解流程}\label{alg:q1}
\begin{algorithmic}[1]
\Require 设备坐标$P_i$与抵达时刻$t_i$（$i=1,\dots,7$），声速$c$
\Ensure 音爆位置$S^{*}$、时刻$t_0^{*}$及参与解算的设备集合
\State 按式\eqref{eq:coord}将经纬高换算为局部直角坐标
\State 遍历全部$\binom{7}{4}=35$个4台组合：由式\eqref{eq:linear}求初值，多初值非线性精炼式\eqref{eq:lsq}，记录各组合的解与RMS残差
\State 对比各组合残差量级，筛查异常设备
\State 以筛查后的5台设备联立解算，按式\eqref{eq:residual}计算全部7台设备的残差，确认异常并剔除
\State 对保留设备做4台子集投票与回测残差对比，检验解的稳健性
\State \Return 五台联合解$(S^{*},t_0^{*})$
\end{algorithmic}
\end{algorithm}

\newpage
\section{问题二：多残骸震动波的归属判定与设备数量分析}

空中有$n=4$个残骸，每个残骸在时刻$\tau_j$于位置$\mathbf{p}_j=(x_j,y_j,z_j)$处产生音爆。地面$m$台设备各记录到$n$个到达时刻，但设备不知道第$k$个读数来自哪个残骸。核心任务有三：建立数学模型确定读数与残骸的对应关系；求出各残骸的音爆位置和时刻；分析至少需要多少台设备。

对残骸$j$与设备$i$，TOA方程为
\begin{equation}
  t_{ik} = \tau_j + \frac{\|\mathbf{p}_j - \mathbf{s}_i\|}{c} + \varepsilon_{ik},
  \label{eq:multi-toa}
\end{equation}
其中$\mathbf{s}_i$为设备$i$坐标，$t_{ik}$为设备$i$的第$k$个读数，$\varepsilon_{ik}$为测量误差。

引入0-1关联变量$a_{ijk}$，当且仅当设备$i$的第$k$个读数来自残骸$j$时$a_{ijk}=1$。一对一约束为
\begin{equation}
  \sum_{j=1}^{n} a_{ijk} = 1,\quad \sum_{k=1}^{n} a_{ijk} = 1,\quad a_{ijk}\in\{0,1\}.
  \label{eq:assignment}
\end{equation}
第一式保证一个读数不能属于多个残骸，第二式保证一台设备对一个残骸只能贡献一次记录。

联合优化目标为最小化全站残差平方和：
\begin{equation}
  \min_{A,\Theta}\; Q = \sum_{i=1}^{m}\sum_{j=1}^{n}\sum_{k=1}^{n} a_{ijk}\Bigl[t_{ik}-\tau_j-\frac{\|\mathbf{p}_j-\mathbf{s}_i\|}{c}\Bigr]^2.
  \label{eq:multi-lsq}
\end{equation}

直接求解上述混合整数非线性问题属于NP-hard。本文采用\textbf{解析种子+全站联合验真}的两层策略，将搜索空间从$(n!)^m$压缩到$n^m$次解析求解。

对某一单事件候选（从$m$台设备各取一个读数，记为$\{t_i\}_{i=1}^{m}$），任选4台设备作种子站，其TOA方程为$\|\mathbf{p}-\mathbf{s}_i\|^2=c^2(t_i-\tau)^2$。将第$i$式减去第1式，$\|\mathbf{p}\|^2$与$\tau^2$两个二次项同时抵消，得到关于$\mathbf{p}$的线性方程组，三个方程联立可将位置表示为时刻的线性函数$\mathbf{p}(\tau)=\mathbf{p}_0+\tau\mathbf{p}_1$。代回第一个设备的原始方程，得到关于$\tau$的一元二次方程，至多两个实根。于是4站定位退化为：解一个$3\times3$线性方程组加一个二次方程——无迭代、无初值依赖、微秒级完成。几何上，两个球面相交于一个圆，该圆躺在两球面的根平面上；三个根平面交于一条直线，音爆点必在此直线上。

以解析种子为初值，用全部$m$台设备做非线性最小二乘精化，计算全站RMSE。RMSE低于阈值（取$0.02$\,s）的候选进入下一层。这一步的鉴别力来自冗余观测：错误关联的``鬼影解''不可能让全部设备的预测到达时刻同时撞上真实读数。

从通过验真的单事件候选中选出$n$个，使每台设备的$n$个读数被恰好各用一次，即解\textbf{精确覆盖问题}（exact cover），目标为最小化联合残差平方和$\sum_{j=1}^{n}\text{RMSE}_j^2$。

设备数由两个独立维度决定。可解性维度：4个未知量$(x,y,z,\tau)$需至少4个方程，故理论下限为4台。但4台只能解一个残骸，无法区分正确关联与鬼影关联，不具备任何冗余校验能力。关联冗余维度：第5台设备提供第一条冗余校验，使模型从``可解''跃升为``可验证''。用几何精度因子（PDOP）量化不同组合的定位精度：
\begin{equation}
  \text{PDOP}=\sqrt{\text{tr}\bigl[(\mathbf{H}^\top\mathbf{H})^{-1}_{1:3,1:3}\bigr]},
\end{equation}
其中$\mathbf{H}$为TOA雅可比矩阵。以问题三设备布局为基准，各组合在最坏残骸位置上的PDOP如表\ref{tab:pdop}所示。

\section{问题四：含随机时间误差的模型修正与布站设计}

问题四设每台设备的记录时刻含$\pm0.5$\,s随机误差。记误差$\varepsilon_{ik}\sim U(-\Delta,+\Delta)$，$\Delta=0.5$\,s，各站各读数相互独立，标准差$\sigma_t=\Delta/\sqrt{3}\approx0.289$\,s。换算成距离，单站测距不确定性达$\pm170$\,m，高出问题三数据自洽水平（亚毫秒）三个数量级，问题二的``枚举—验真—覆盖''管道直接套用会失效，必须修正。本问题分三步处理：先修正模型使其在误差环境下仍能正确关联与定位，再对问题三数据叠加随机误差做蒙特卡洛误差分析，最后在误差无法降低的前提下设计加密台网方案并仿真验证。

原管道在两个环节失效。其一是阈值失效：正确关联的全站残差不再接近零，而是噪声本身的量级（约$\pm0.3$\,s），继续沿用0.02\,s的验真阈值，100次实验中79次连4个候选都凑不齐，真解被自己的阈值误杀。其二是种子退化：解析种子由4站差分方程生成，噪声经几何放大后，固定一组种子站约有31\%的概率给出偏离真解过远的种子，正确组合在初筛阶段就被丢弃。

针对阈值失效，用蒙特卡洛模拟把噪声传播到残差域，分别标定正确关联与错误关联的残差分布，结果如表\ref{tab:q4-calib}所示。据此取严阈值RMSE$<0.55$\,s且max$|$残差$|<0.65$\,s：正确关联通过率超过99\%，错误关联绝大多数被拦在门外。需要承认的是鉴别间隙明显变窄：无噪声时是0.0002\,s对数秒的差别，$\pm0.5$\,s噪声下是0.30\,s对0.43\,s——错误关联经4参数最小二乘拟合的摊薄，最优者也能压到0.43\,s。这正是下一项容错机制存在的理由。

针对变窄的鉴别间隙，加入两级容错。第一级为严阈值路径：按RMSE$<0.55$\,s且max$|$残差$|<0.65$\,s枚举候选，走精确覆盖，约99\%的实验在此直接得到唯一覆盖。第二级为剩余读数补全：若个别正确关联因极端噪声实现（约0.3\%的概率max$|$残差$|$超过0.65\,s）被误杀，导致候选只有3个——此时3个已确认候选锁定7站共21个读数，每台设备恰好剩下1个未用读数，其组合在物理上必然属于第4个残骸，直接把这7个剩余读数送去精化并用宽阈值（RMSE$<0.9$\,s）验证即可。三项修正均不改变问题二模型的框架骨架，改动集中在阈值从哪来、种子退化怎么办、边界情形如何兜底三处。

\subsection{模型对比}
将本文方法与传统TDOA方法对比：TDOA用时刻差消去$t_0$，方程数比设备数少1，同样的台数下冗余更少，且无法直接给出音爆时刻；本文的TOA模型保留$t_0$为未知量，每台设备贡献一个独立方程，冗余度更高，契合异常数据检验的需要。在初值求取环节，本文借用了TDOA的差分思想消去二次项，相当于两种体制的结合。与直接以全部7台数据做最小二乘的朴素做法相比，本文的子集枚举与残差检验避免了D、F异常记录对解的污染——若7台混用，解将被拉向错误位置且难以察觉。

%================ 11 模型的评价、改进与推广 =================
\section{模型的评价、改进与推广}

\subsection{模型的优点}

本文模型的核心优势是关联鉴别力的稳健性。``枚举—验真—覆盖''框架在无噪声与$\pm0.5$\,s噪声下的关联成功率均为100\%，六项压力测试进一步表明，除噪声超出设计值60\%以上或单站2\,s级粗差外，各类极端噪声形态下关联零失败、零混淆；且鉴别力来自全部设备的联合TOA一致性，不依赖5秒时间窗等先验条件。

求解效率与确定性强。解析种子把4站定位退化为一个$3\times3$线性方程组加一个一元二次方程，无迭代、无初值依赖、微秒级完成，不存在迭代法不收敛或陷入局部极小的风险；整条枚举链路向量化后单次求解约0.1\,s，使数百次蒙特卡洛统计成为常规验证手段。

异常诊断能力内建于模型。问题一中子集枚举与残差回测自然识别出D、F的异常记录，问题三的逐站残差诊断确认7台全部可靠，问题四的容错补全机制在严阈值误杀真解时自动兜底——模型在回答``位置在哪''的同时回答了``数据是否可信''。

精度预算可直接指导工程设计。$\sigma_{\text{3D}}\approx\text{PDOP}\times\sigma_t$的线性预算与实测吻合（预算283\,m对实测95\%分位457\,m），台网规模与布局可以先算后建；噪声扫描实验显示崩溃点之前误差与噪声界近似成正比，模型行为完全可预测。

\subsection{模型的缺点}

验真阈值依赖噪声形态。严阈值按均匀分布标定，在两点分布这类顶满边界的噪声下误杀率升至76\%，需要靠补全机制兜底；噪声形态改变时阈值需重新标定。

粗差防御缺位。模型不能防御2\,s级单站粗差，7台情形下约半数失败；20台方案的阶段一仍依赖原7台子网，粗差恰好落在子网上时关联阶段即被污染，这是当前明确的能力边界。

高程精度受观测几何的硬约束。地面台网对高空目标的垂直张角天然不足，7台现状在标称噪声下本就有10.4\%的实验超过1\,km，只能靠中心站等针对性布设补偿，硬件代价较大。

枚举复杂度随规模增长。$4^7$的枚举对本题可行，但残骸数或子网台数继续增大后，阶段一的全枚举不再现实，需要引入启发式关联，此时关联的最优性不再有穷举保证。

\subsection{模型的改进与推广}

针对上述缺点，可行的改进有四：其一，验真阈值按更保守的两点分布重新标定，或按实测噪声形态自适应调整；其二，精化后增加一步``最大残差超过1\,s则剔除该站重解''的野值检验，补上粗差防御；其三，两阶段法的阶段一改从台网中随机抽取多个子网并行求解、多数表决，消除单个子网被污染的失效模式；其四，精化目标从最小二乘改为最小化最大残差（$L_\infty$准则），它与均匀分布噪声的最大似然估计形式一致，理论上比最小二乘更适配本题的噪声模型；此外，利用残骸弹道先验（音爆点必在飞行轨迹上）可把三维定位降维为沿轨迹的一维参数估计，进一步压缩误差。

本文框架可直接推广到地震震源定位、水下声学信标定位、雷电甚高频定位、爆炸与枪声声源定位等多站到达时间定位场景；``解析种子+全站验真+精确覆盖''的关联机制适用于各类多事件归属判定问题；``子网定关联、全网提精度''的两阶段思想与PDOP精度预算方法，对传感器组网设计具有一般性的参考价值。

\subsection{问题一模型求解（\texttt{q1\_solution.py}）}
\begin{lstlisting}[language=Python, caption=问题一完整求解代码]
import numpy as np
from itertools import combinations
from scipy.optimize import least_squares

# ================= 数据（问题 1） =================
devs = {
    'A': (110.241, 27.204, 824, 100.767),
    'B': (110.780, 27.456, 727, 112.220),
    'C': (110.712, 27.785, 742, 188.020),
    'D': (110.251, 27.825, 850, 258.985),
    'E': (110.524, 27.617, 786, 118.443),
    'F': (110.467, 27.921, 678, 266.871),
    'G': (110.047, 27.121, 575, 163.024),
}
c = 340.0                        # 声速 m/s
lon0, lat0 = 110.241, 27.204     # 局部坐标原点（设备 A）
Klon, Klat = 97.304e3, 111.263e3  # 每度折合米数

# 经纬度 -> 局部东-北-天直角坐标 (m)
pos = {k: np.array([(v[0]-lon0)*Klon, (v[1]-lat0)*Klat, float(v[2])])
       for k, v in devs.items()}
tobs = {k: v[3] for k, v in devs.items()}

# ================= 核心函数 =================
def residual(v, P, T):
    """残差 r_i = 几何距离 ||S-P_i|| - 声波距离 c*(t_i-t0)，单位米。
       v = [x, y, z, t0]；P: n×3 设备坐标；T: n 个到达时刻。"""
    return np.linalg.norm(P - v[:3], axis=1) - c * (T - v[3])

def solve_toa(keys):
    """TOA 定位：线性化求初值 + 多初值非线性精炼，返回 (RMS残差, 解向量)"""
    P = np.array([pos[k] for k in keys])
    T = np.array([tobs[k] for k in keys])
    # 第一步：平方后两两相减，得关于 (x,y,z,t0) 的线性方程组
    A, b = [], []
    for i in range(1, len(keys)):
        A.append(np.concatenate([2*(P[i]-P[0]), [-2*c**2*(T[i]-T[0])]]))
        b.append(P[i] @ P[i] - P[0] @ P[0] - c**2*(T[i]**2 - T[0]**2))
    X, *_ = np.linalg.lstsq(np.array(A), np.array(b), rcond=None)
    t0_init = X[3] if np.isfinite(X[3]) else 15.0
    # 第二步：多初值 LM 精炼，防伪解分支
    inits = [X[:3]] + [np.array([(110.5-lon0)*Klon, (27.31-lat0)*Klat, z])
                       for z in (1000.0, 5000.0, 12000.0)]
    best = None
    for x0 in inits:
        r = least_squares(residual, np.concatenate(
            [x0, [t0_init]]), args=(P, T))
        rms = np.sqrt(np.mean(r.fun**2))
        if best is None or rms < best[0]:
            best = (rms, r.x)
    return best

def lonlat(v):
    """局部坐标解 -> (经度, 纬度, 高程, t0)"""
    return lon0 + v[0]/Klon, lat0 + v[1]/Klat, v[2], v[3]

# ============ 第 1 步：4 台子集枚举，发现异常 ============
print("== 4 台组合枚举（仅列物理合理解）==")
for combo in combinations(devs, 4):
    rms, v = solve_toa(list(combo))
    lo, la, z, t0 = lonlat(v)
    if rms < 500 and 0 < z < 20000 and -60 < t0 < 300:
        print(f"{''.join(combo)}: RMS={rms:6.1f}m  ({lo:.4f},{la:.4f}) "
              f"z={z:6.0f}m t0={t0:6.2f}s")

# ====== 第 2 步：残差检验，确认 D、F 异常 ======
rms5, v5 = solve_toa(list('ABCEG'))
print("\n== ABCEG 五台联合解 ==")
print("经度 %.5f  纬度 %.5f  高程 %.0f m  t0 %.3f s  RMS %.1f m"
      % (*lonlat(v5), rms5))
P_all = np.array([pos[k] for k in devs])
T_all = np.array([tobs[k] for k in devs])
for k, r in zip(devs, residual(v5, P_all, T_all)):
    print(f"  设备{k}: 残差 {r:+9.1f} m ({r/c:+6.2f} s)")

# ============ 第 3 步：子集投票 ============
print("\n== {A,B,C,E,G} 内 4 台子集投票 ==")
for combo in combinations('ABCEG', 4):
    rms, v = solve_toa(list(combo))
    lo, la, z, t0 = lonlat(v)
    print(f"{''.join(combo)}: ({lo:.4f},{la:.4f}) z={z:5.0f}m t0={t0:5.2f}s")

# ====== 第 4 步：蒙特卡洛噪声散布评估 ======
rng = np.random.default_rng(0)
keys5 = list('ABCEG')
P5 = np.array([pos[k] for k in keys5])
T5 = np.array([tobs[k] for k in keys5])

def monte_carlo(coord_noise_deg, time_noise_s, n=300):
    outs = []
    for _ in range(n):
        dP = P5 + rng.uniform(-coord_noise_deg, coord_noise_deg, P5.shape) \
                 * np.array([Klon, Klat, 0.0])   # 高程视为精确
        dT = T5 + rng.uniform(-time_noise_s, time_noise_s, T5.shape)
        r = least_squares(residual, v5.copy(), args=(dP, dT))
        outs.append(r.x)
    outs = np.array(outs)
    dh = np.hypot(outs[:, 0]-v5[0], outs[:, 1]-v5[1])
    return np.percentile(dh, 95), outs[:, 2].std()

r95a, zsa = monte_carlo(0.0005, 0.0005)   # 坐标量化 + 时刻舍入
r95b, zsb = monte_carlo(0.0,    0.5)      # ±0.5 s 时间误差（问题4水平）
